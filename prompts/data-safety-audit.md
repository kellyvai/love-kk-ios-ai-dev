# 数据有效性与安全审查框架

检查应用在数据进出、存储和隐私上的风险（D2 审查 4 调用）。

---

## 审查维度

### 1. 输入验证

**检查项：**
- [ ] 文本字段有长度限制
- [ ] 特殊字符有过滤或转义
- [ ] 用户未登录时不写库，直接返回
- [ ] 客户端校验之外，服务端也有校验

### 2. 输出验证

**检查项：**
- [ ] 从数据库或接口返回的数据有有效性检查（空值、类型、范围）
- [ ] AI 返回的内容在前端有兜底校验，不直接信任

### 3. 敏感数据

**检查项：**
- [ ] 所有网络传输走 HTTPS
- [ ] 密钥、令牌不写在客户端代码里
- [ ] 敏感信息显示时已脱敏
- [ ] 数据库访问权限（如行级安全策略）按用户隔离

### 4. 用户隐私

**检查项：**
- [ ] 没有申请不必要的权限，每个权限都有清晰的用途说明
- [ ] 数据保存期限合理，提供删除账号和数据的途径
- [ ] 隐私政策与实际收集的数据一致

---

## 输出格式

```
问题：[用户或数据会遇到什么风险]
位置：[文件或功能]
严重程度：关键 / 重要 / 可选
修复方案：[怎么改]
验证方法：[改完怎么确认]
```
